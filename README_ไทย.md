# แนะแนวสาขา TCAS — ชุดไฟล์สำหรับ GitHub Pages

ไฟล์เว็บไซต์อยู่ระดับบนสุดของ ZIP แล้ว โดยมี `index.html` อยู่โฟลเดอร์แรก พร้อม `styles.css`, `src/` และ `data/` ที่หน้าเว็บต้องใช้ เส้นทางไฟล์ถูกปรับให้รองรับการเปิดเว็บใต้ชื่อ repository เช่น `/<ชื่อ-repository>/` ด้วย

เปิดในเครื่องได้จากโฟลเดอร์นี้ด้วยคำสั่ง `npm run dev` แล้วไปที่ `http://localhost:3000`

`project_docs/` เก็บแผนงานและบันทึกที่มา ส่วน `source_files/` เก็บไฟล์ต้นฉบับและภาพอ้างอิง ทั้งสองโฟลเดอร์ไม่จำเป็นต่อการทำงานของเว็บไซต์ หากนำเว็บไปไว้ใน GitHub repository สาธารณะ อย่าอัปโหลดสองโฟลเดอร์นี้ถ้าไม่ต้องการเผยแพร่เอกสาร/ต้นฉบับเหล่านั้น ข้อมูลใน `data/*.json` ที่เว็บใช้จะเข้าถึงได้สาธารณะตามการทำงานของ GitHub Pages

หมายเหตุ: ไฟล์นี้เตรียมโครงเว็บสำหรับ Pages ไว้แล้ว แต่เว็บไซต์ยังไม่ได้ถูกเผยแพร่ขึ้น GitHub Pages
