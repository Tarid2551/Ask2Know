# แนะแนวสาขา TCAS — ไฟล์ส่งมอบ

ชุดนี้รวมไฟล์เว็บ ข้อมูลหลักสูตร แบบสอบถาม และไฟล์ต้นทางที่ใช้ประกอบงานไว้ด้วยกันครับ

## เปิดเว็บในเครื่อง

ต้องมี Node.js และ Python 3 จากโฟลเดอร์ `tcasmatch` รันคำสั่งนี้ได้เลย:

```bash
npm run dev
```

จากนั้นเปิด `http://localhost:3000`

## ไฟล์หลัก ๆ อยู่ตรงไหน

- `src/` — ส่วนหน้าเว็บ แบบสอบถาม การจับคู่ และข้อมูลเกณฑ์ MyTCAS
- `data/` — ข้อมูลหลักสูตร ชุดคำถาม และรายวิชาที่เกี่ยวกับเกณฑ์คะแนน
- `source_files/` — Excel ชุดคำถาม และเอกสารอ้างอิงที่ใช้ทำงาน
- `plan.md` และ `TODO.md` — แผนงานและรายการสิ่งที่ทำไว้

> หมายเหตุ: ตัวกรองคุณสมบัติจะตรวจข้อมูลสดจาก MyTCAS หลังจากจำกัดผลค้นหาแล้ว และตรวจได้ไม่เกิน 100 รหัสต่อครั้ง เพื่อไม่ให้เรียกข้อมูลจำนวนมากเกินไป

ถ้ากำลังจะสมัครจริง แนะนำให้เปิดประกาศของรอบนั้นบน MyTCAS อีกครั้งนะครับ เพราะเงื่อนไขอาจเปลี่ยนได้ ผลจับคู่ในเว็บนี้มีไว้ช่วยสำรวจ ไม่ใช่การรับประกันว่าจะผ่านการคัดเลือก
