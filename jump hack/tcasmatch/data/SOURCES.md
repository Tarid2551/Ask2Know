# แหล่งข้อมูลภายนอกที่ใช้เป็นลิงก์ประกอบ

## MyTCAS

- Directory สถาบัน: https://course.mytcas.com/universities
  - หน้าที่ตรวจระบุ “ข้อมูลการรับสมัครของมหาวิทยาลัย ปีการศึกษา 2570” และลิงก์หน้ารายละเอียดสถาบัน/เอกสารประกาศในแต่ละรอบ
  - เว็บไซต์จึงเพิ่มลิงก์ออกไปยัง directory ทางการ แทนการคัดลอกข้อมูลเอกสารที่อาจอัปเดตได้
- ตัวอย่างหน้าสถาบัน: https://course.mytcas.com/universities/018
  - หน้ามหาวิทยาลัยอุบลราชธานีแสดงรายชื่อคณะและลิงก์ต่อไปยังหน้ารายละเอียดคณะ
- ตัวอย่างหน้าหลักสูตร: https://course.mytcas.com/programs/10320104112101A
  - หน้าที่ตรวจมีชื่อหลักสูตรภาษาไทย/อังกฤษ ประเภทหลักสูตร วิทยาเขต ค่าใช้จ่าย ค่ามัธยฐานเงินเดือน และจำนวนรับแยกรอบ 1–4; ฟิลด์เหล่านี้อาจมีหรือไม่มีในแต่ละหลักสูตรและอาจเปลี่ยนตามปี

ในเว็บไซต์แนะแนว ลิงก์รายหลักสูตรสร้างจาก `programId` เมื่อผ่านรูปแบบรหัส 12–14 หลักและอักษรต่อท้ายที่เป็นตัวเลือก; URL ที่ใช้คือ `https://course.mytcas.com/programs/{programId}`. ลิงก์เปิดหน้าต่างใหม่พร้อม `rel="noopener noreferrer"`. ข้อมูลคะแนน/น้ำหนักใน Excel ไม่ถูกแก้และไม่มีการคัดลอกค่ารับสมัคร/ค่าใช้จ่าย/เงินเดือนจาก MyTCAS มาเก็บแบบคงที่ เพื่อให้ผู้ใช้ตรวจข้อมูลปัจจุบันจาก MyTCAS โดยตรง.


## เกณฑ์รับสมัครรายโครงการ/รอบใน MyTCAS

- หน้าหลักสูตรเปิดรายละเอียดรายรอบและรายโครงการด้วย JavaScript; ตัวอย่างที่ตรวจ: https://course.mytcas.com/programs/10320104112101A (ราชวิทยาลัยจุฬาภรณ์), https://course.mytcas.com/programs/10040104902601A (มหาวิทยาลัยเชียงใหม่), และ https://course.mytcas.com/programs/10240114501101A (มหาวิทยาลัยแม่ฟ้าหลวง). เมื่อเลือกแท็บรอบและโครงการแล้ว หน้าแสดงเงื่อนไขคะแนนและ/หรือ “การคำนวณคะแนน”; บางโครงการเป็น Portfolio/สัมภาษณ์หรือชี้ไปประกาศของมหาวิทยาลัย
- JavaScript ทางการที่ https://course.mytcas.com/static/js/main.03d554bd.chunk.js ระบุ source data endpoint `https://my-tcas.s3.ap-southeast-1.amazonaws.com/mytcas/rounds/{programId}.json?ts=...`. Endpoint ส่ง JSON สาธารณะพร้อม `Access-Control-Allow-Origin: *` (ตรวจ `GET` วันที่ 14 ต.ค. 2569)
- ตัวอย่าง `rounds/10320104112101A.json` มี 3 project records. รอบ 3 มี `scores` เช่น `{tgat:20,a_lv_61:12,a_lv_64:12,a_lv_65:12,a_lv_66:12,a_lv_82:12,cal_type:"1",cal_score_sum:20,cal_subject_name:"tgat a_lv_61 a_lv_64 a_lv_65 a_lv_66 a_lv_82"}` และ `score_conditions` เช่น `min_gpax`, `min_tgat`, `subject_names`, `score_minimum`; แสดงให้ตรงกับข้อมูลต้นทางและไม่แปลคีย์ผิด
- ตัวอย่าง `rounds/10040104902601A.json` มีหลาย project รอบ 1 ซึ่งเกณฑ์ portfolio/สัมภาษณ์ใช้สัดส่วนได้ เช่น 40%/60%, และอาจมีลิงก์ประกาศมหาวิทยาลัยเพิ่มเติม
- ตัวอย่าง `rounds/10240114501101A.json` แสดงหลายโครงการในรอบ 3 ที่ใช้ชุดวิชาและคะแนนขั้นต่ำต่างกัน; บางโครงการมีขั้นต่ำแต่ไม่มีน้ำหนักคำนวณในข้อมูล JSON ที่อ่านได้ ดังนั้น “ไม่มีข้อมูล” ต้องไม่แสดงเป็น 0% และต้องไม่ประกอบสูตรขึ้นเอง

URL รอบสมัครข้างต้นเป็นข้อมูลจาก MyTCAS TCAS70 ซึ่งเปลี่ยนได้; เว็บไซต์โหลดข้อมูลตาม `programId` เมื่อผู้ใช้เปิดรายละเอียด แล้วแสดงรอบ/โครงการ น้ำหนัก คะแนนขั้นต่ำ และสถานะไม่พบข้อมูลแยกกัน พร้อมคงลิงก์กลับหน้าหลักสูตร MyTCAS. ไม่เพิ่มการป้อนคะแนนผู้สมัครหรือเครื่องคิดคะแนนรับเข้า.

- `data/mytcas_score_subjects.json` เก็บ mapping 120 รหัสคะแนนเป็นชื่อ/ชื่อย่อ/คะแนนเต็มจาก metadata ที่ฝังใน JavaScript หน้าเว็บ MyTCAS `https://course.mytcas.com/static/js/main.03d554bd.chunk.js` ณ 14 ต.ค. 2569; เมื่อรหัสใหม่ไม่อยู่ใน mapping หน้าเว็บจะแสดงรหัสจาก MyTCAS แทนการตั้งชื่อเดา
หน้า frontend ของ MyTCAS แปล `score_condition: 1` เป็นเกณฑ์คะแนนขั้นต่ำของวิชาใดวิชาหนึ่งใน `subject_names` และ `score_condition: 2` เป็นคะแนนขั้นต่ำของผลรวม; `scores.cal_subject_name` ใช้ `|` แยกกลุ่มทางเลือก และเวอร์ชันหน้าเว็บที่ตรวจแสดงกลุ่มเหล่านั้นเป็น “หรือ”. เว็บไซต์แนะแนวคงข้อความเงื่อนไขนี้แยกจากสัดส่วนคะแนน ไม่คำนวณผลคะแนนผู้สมัคร.


## คุณสมบัติการศึกษาของผู้สมัคร MyTCAS
- ตัวอย่างหน้าโครงการ TCAS70: https://course.mytcas.com/programs/10320104112101A และ https://course.mytcas.com/programs/10040104902601A. หน้า MyTCAS แสดงคุณสมบัติ “หลักสูตรแกนกลาง”, “หลักสูตรนานาชาติ”, “หลักสูตรอาชีวะ”, “หลักสูตรตามอัธยาศัย (กศน.)” และ “หลักสูตร GED” แยกรายโครงการ
- JavaScript ทางการ: https://course.mytcas.com/static/js/main.03d554bd.chunk.js แสดงการอ่านฟิลด์ `only_formal`, `only_international`, `only_vocational`, `only_non_formal` และ `only_ged`; ค่า `1` แสดงเป็นรับ และค่า `2` แสดงเป็นไม่รับ. เว็บไซต์แนะแนวคงสถานะที่ไม่มี/ไม่รู้จักเป็น “ไม่มีข้อมูลใน MyTCAS” แทนการสรุปว่าไม่รับ.
- JSON รายโครงการ/รอบ: https://my-tcas.s3.ap-southeast-1.amazonaws.com/mytcas/rounds/{programId}.json. ตรวจตัวอย่างวันที่ 14 ต.ค. 2569; แต่ละหลักสูตรต้องดึงแยกตามรหัส และไม่พบ endpoint รวมสำหรับคุณสมบัติ. ชุดข้อมูลหลักสูตรมี 3,437 `programId` ไม่ซ้ำ จึงให้ผู้ใช้จำกัดผลด้วยคำค้น/มหาวิทยาลัย/คณะ/ประเภทก่อน แล้วจึงโหลดสดเฉพาะรหัสที่ไม่เกิน 100 รหัสต่อครั้ง; ไม่สร้าง snapshot ทั้งประเทศ.
