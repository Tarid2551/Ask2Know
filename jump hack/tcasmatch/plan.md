# แผนเว็บไซต์แนะแนวสาขา TCAS

## เป้าหมายและขอบเขต
เว็บไซต์ภาษาไทยช่วยสำรวจความสนใจ บุคลิกภาพ และความถนัด แล้วจัดอันดับ/ค้นหาหลักสูตรจากข้อมูล Excel ของผู้ใช้ เพื่อเป็นเครื่องมือประกอบการสำรวจ ไม่ใช่เครื่องมือวินิจฉัยหรือคาดการณ์การรับเข้า หน้าแรกเปิดแบบสอบถามทันที และยังคงหน้า ผล วิธีคิด และไดเรกทอรีหลักสูตรไว้ใน navigation เดิม

## ข้อมูลและการคำนวณ
- `data/programs.json` คงข้อมูลหลักสูตรตามแถว Excel ต้นฉบับและค่า weight ทั้ง 18 คอลัมน์; ไม่เติมข้อมูลช่องว่างหรือรวมแถวที่ `programId` ซ้ำ
- `data/question_bank.json` มาจาก workbook คำถาม 3 ชีต; 2 คำถามพหุปัญญาที่ไม่มีหมวดและ 1 ข้อที่มีหลายหมวดไม่ถูกสุ่มใช้
- `src/questionnaire.js` สุ่มแบบแบ่งชั้นหัวข้อละ 15 ข้อ รวม 45 ข้อ: Big Five 3 ข้อต่อ trait, RIASEC 2–3 ข้อต่อ type และพหุปัญญา 1–2 ข้อต่อมิติที่จัดหมวดได้; คำตอบอยู่ใน state ของเบราว์เซอร์
- `src/match.js` เฉลี่ยคำตอบในแต่ละมิติ แปลงระดับ 1–5 เป็น 0–1 และกลับทิศ N− จาก N+; จัดอันดับด้วยคะแนนภาพรวม 55% และคะแนนเน้นมิติเด่น 45% พร้อมปรับตามความครอบคลุมของน้ำหนัก; คะแนนเสมอถูกจัดการโดยไม่สร้างจุดเด่นเทียม
- Musical และ Bodily-kinesthetic แสดงในโปรไฟล์เท่านั้น เพราะชุด Excel ไม่มีคอลัมน์น้ำหนักสำหรับสองมิตินี้; ไม่อนุมานว่า Musical เท่ากับ RIASEC Artistic
- ผลทั้งหมดเป็นดัชนีสำรวจ เนื่องจากแหล่ง Excel ไม่กำหนดสูตรสร้างน้ำหนักหรือเกณฑ์สอบผ่าน

## การเสริมข้อมูล MyTCAS
ใช้ [MyTCAS ข้อมูลสถาบัน](https://course.mytcas.com/universities) เป็นไดเรกทอรีทางการ และแสดงเกณฑ์สมัคร TCAS70 ในรายละเอียดหลักสูตรจาก JSON สาธารณะ `https://my-tcas.s3.ap-southeast-1.amazonaws.com/mytcas/rounds/{programId}.json`. โหลดตาม `programId` เมื่อเปิดรายละเอียด จากนั้นแสดงตามรอบและโครงการ: วิชาที่ใช้/สัดส่วนจาก `scores`, คะแนนขั้นต่ำ/GPAX จาก `score_conditions` และชื่อวิชาจาก mapping สาธารณะของ MyTCAS. ถ้าไม่มีข้อมูล ห้ามแทนด้วย 0% หรือคาดเดาสูตร; แยกสถานะกำลังโหลด, ไม่พบข้อมูล และโหลดล้มเหลว. คงลิงก์ไปหน้าหลักสูตรทางการ `https://course.mytcas.com/programs/{programId}` เพื่อประกาศฉบับเต็ม. ไม่ดึงข้อมูลทุกหลักสูตรมาเก็บเป็น snapshot, ไม่เพิ่มช่องกรอก/เครื่องคิดคะแนนรับเข้า และไม่รวมเกณฑ์สอบเข้ากับดัชนีแนะแนวจากแบบสอบถาม

## รูปแบบการใช้งาน
แบบสำรวจทีละข้อใช้มาตร 1–5 บังคับตอบก่อนเดินหน้าต่อ ย้อนกลับ/ทบทวนได้ และเริ่มใหม่เพื่อสุ่มชุดใหม่; ผลแสดงโปรไฟล์ เหตุผลคะแนน และอันดับหลักสูตรพร้อมตัวกรองตามกลุ่มคะแนน; ไดเรกทอรีค้นหา เรียง และกรองหลักสูตร พร้อมรายละเอียดแถว Excel และเกณฑ์ MyTCAS แยกรอบ/โครงการ; หน้า “วิธีคิด” อธิบายสูตร ที่มา และข้อจำกัด

## สถาปัตยกรรมและโครงสร้างไฟล์
เว็บ static ฝั่งไคลเอนต์ ใช้ HTML, CSS และ JavaScript ES modules แบบไม่เพิ่ม dependency หรือ backend; เสิร์ฟด้วยคำสั่ง `npm run dev` และ Python HTTP server บนพอร์ต 3000

- `index.html` — shell, navigation, metadata และ mount point ของแอป
- `styles.css` — layout เดิมของแบบสอบถาม/ผล/ไดเรกทอรี และธีมสี
- `src/app.js` — โหลดข้อมูล, ควบคุม state/rendering, แบบสำรวจ, ผล, ค้นหาหลักสูตร, modal และลิงก์ MyTCAS
- `src/questions.js` — มิติ/ป้ายชื่อและรหัสน้ำหนักที่แมปได้
- `src/questionnaire.js` — สุ่มแบบแบ่งชั้นและสับลำดับคำถาม
- `src/match.js` — สร้างโปรไฟล์ คัดจุดเด่น คำนวณคะแนน และจัดอันดับ
- `src/mytcas.js` — โหลดและจัดรูปเกณฑ์รับสมัคร MyTCAS ตามรอบ/โครงการเมื่อเปิดรายละเอียดหลักสูตร; แสดงน้ำหนัก `scores`, ขั้นต่ำ `score_conditions` และสถานะข้อมูลขาด/โหลดไม่สำเร็จ โดยไม่ตีความค่าที่ไม่มี
- `data/programs.json` — ข้อมูลหลักสูตรจาก Excel
- `data/question_bank.json` — คลังคำถามจาก workbook
- `data/mytcas_score_subjects.json` — รหัสวิชา ชื่อไทย ชื่อย่อ และคะแนนเต็มจาก metadata สาธารณะของหน้า MyTCAS
- `data/SOURCES.md` — URL และข้อเท็จจริง MyTCAS ที่ตรวจ พร้อมนโยบาย provenance
- `manus-routes.json` — ประกาศ route ของเว็บ (มี `/` เดียว เนื่องจากหน้าเปลี่ยนผ่าน client-side)
- `TODO.md` — เกณฑ์พฤติกรรมและสถานะงาน
- `app.config.ts`, `favicon.svg`, `logo.svg` — metadata และทรัพยากรตราสัญลักษณ์

## แผนการออกแบบ

### Design Movement
พอร์ทัลบริการการศึกษาไทยร่วมสมัย ผสม editorial layout แบบสถาบันสาธารณะกับความนุ่มนวลของเครื่องมือสำรวจตนเอง ยึดโทนและบรรยากาศเว็บ TCAS ที่ผู้ใช้ให้เป็นภาพอ้างอิง แต่คงองค์ประกอบและลำดับหน้าเดิมของเว็บไซต์แนะแนว

### Core Principles
1. อ่านง่ายและเป็นทางการพอดี: ชื่อหัวข้อ ลำดับคำถาม และสถานะมี hierarchy ชัด
2. โปร่งใสเหนือการชี้นำ: คะแนน เหตุผล และแหล่งข้อมูลแยกให้เห็นชัด
3. คงเส้นทางเดิม: เปลี่ยนเฉพาะสี/ธีม ไม่รื้อ layout หรือความหมายของข้อมูล
4. เชื่อมต้นทางได้: ข้อมูลทางการที่เปลี่ยนตามปีเปิดจาก MyTCAS โดยตรง

### Color Philosophy
พื้นฟ้าอ่อนสื่อความเปิดกว้างและสงบ น้ำเงินเข้มให้ความน่าเชื่อถือแบบพอร์ทัลสถาบัน สี teal ใช้เน้นการโต้ตอบและลิงก์ ส่วนทองใช้เป็น accent สำหรับ progress/จุดสำคัญ สีทั้งหมดเปลี่ยนผ่าน CSS variables โดยรักษาสัดส่วนและ contrast ขององค์ประกอบเดิม

### Layout Paradigm
คง layout ที่มีอยู่: header/navigation ด้านบน, แบบสอบถามอ่านตามลำดับใน question panel พร้อม rail ความคืบหน้า, ผลลัพธ์เป็นการ์ดคะแนน, และไดเรกทอรีเป็นรายการกรองได้ ไม่เปลี่ยนเป็นแถบไอคอนหรือทำหน้ารายชื่อมหาวิทยาลัยแทนหน้าแบบสอบถาม

### Signature Elements
- แถบความคืบหน้าสีทองบนพื้นฟ้า/น้ำเงิน
- ป้ายหมวดและแถบคะแนน teal ที่ต่อเนื่องจากธีมเดิม
- การ์ดพื้นขาวสะอาดและเส้นแบ่งสีน้ำเงินอ่อน ช่วยให้ข้อมูลจำนวนมากอ่านง่าย

### Interaction Philosophy
โต้ตอบอย่างมีจังหวะและไม่เร่งรัด: ตอบข้อหนึ่งก่อนจึงไปต่อ ย้อน/ทบทวนได้ อธิบายคะแนนและลิงก์ต้นทางก่อนตัดสินใจ ลิงก์ MyTCAS เปิดแท็บใหม่เพื่อไม่ทำให้คำตอบ/flow ในแบบสำรวจหาย

### Animation
ใช้ transition สั้นและละเอียดกับปุ่ม การ์ด และ progress เท่าที่มีอยู่; ไม่เพิ่ม parallax/animation ตกแต่ง และปฏิบัติตาม `prefers-reduced-motion` สำหรับการเลื่อนและการเคลื่อนไหว

### Typography System
ใช้ IBM Plex Sans Thai เป็นหลักสำหรับภาษาไทย และ Manrope สำหรับตัวเลข/label ภาษาอังกฤษ; heading ใช้น้ำหนักปานกลางกับขนาด responsive, body 13–15px โดยประมาณ, micro-label ใช้ขนาดเล็กพร้อม letter spacing เพื่อแยกจากข้อความหลัก

### Brand Essence
“แนะแนวข้อมูลหลักสูตร TCAS ด้วยการสำรวจตนเองและแหล่งทางการที่ตรวจต่อได้” บุคลิก 3 คำ: รอบคอบ, เปิดเผย, เป็นมิตร

### Brand Voice
หัวข้อชวนคิดอย่างไม่ตัดสิน; ปุ่มใช้คำกริยาตรงไปตรงมา; microcopy ย้ำสิทธิ์เลือกและข้อจำกัดของคะแนน ตัวอย่าง: “สำรวจจากสิ่งที่คุณสนใจ แล้วค่อยเปิดทางเลือก” และ “คะแนนนี้ช่วยตั้งคำถาม ไม่ได้เลือกอนาคตแทนคุณ”

### Wordmark & Logo
ใช้สัญลักษณ์วงกลมเอียงกับแท่ง 3 ระดับและจุดสีทองที่มีใน wordmark ปัจจุบัน สื่อถึงแผนที่ตัวเลือกและการเติบโต โดยใช้สีเขียวเดิมใน artwork ต่อไปตามค่า design token ใหม่

### Signature Brand Color
Teal น้ำเงิน `#168e9c` เป็นสีเน้นที่จดจำง่ายสำหรับลิงก์และการโต้ตอบ บนพื้นฟ้าอ่อน `#eaf4ff` และน้ำเงินเข้ม `#173f68`


## ปรับตามคำขอล่าสุด
- คงโครงหน้าและงานเดิมไว้ แต่จัดเมนูหลัก 3 รายการให้อยู่กึ่งกลางแถบ header และขยายขนาด/พื้นที่กด: “แบบสอบถาม”, “สำรวจหลักสูตร”, “วิธีการคำนวณ”; active state และการเปิดหน้าเดิมต้องคงเดิม ส่วนมือถือยังใช้เมนูยุบ/ปุ่ม toggle ที่มีอยู่
- ซ่อนตัวเลขจำนวนรับจากทุกส่วนที่ผู้ใช้เห็น ไม่ว่าจะมาจาก Excel (`acceptance`, `majorAcceptance`) หรือข้อมูลโครงการ MyTCAS (`receive_student_number`); คงข้อมูลต้นทางและตรรกะที่ไม่แสดงค่าไว้ ไม่ลบ/แก้ตัวเลขในชุดข้อมูล


## ลดความหนาแน่นของข้อความ
ลดเฉพาะป้าย/คำอธิบายที่ซ้ำกันในหน้าคำถาม: ใช้ตัวนับความคืบหน้าเพียงจุดเดียว ตัดป้าย QUESTION ที่ซ้ำ และย่อข้อความ privacy/แหล่งอ้างอิง โดยยังคงคำถาม คำสั่งตอบ มาตร 1–5 ที่มา worksheet/แถว และคำเตือนสำคัญไว้ครบ; หน้าสำรวจหลักสูตรยุบรายละเอียดตรวจข้อมูลรองไว้ใน disclosure ที่เปิดดูได้ ส่วนหน้า “วิธีการคำนวณ” และเกณฑ์ MyTCAS ที่จำเป็นไม่ตัดทอน


## หน้าทบทวนคำตอบ
ลดป้ายซ้ำที่ย้ำสถานะเดียวกับหัวข้อหน้าและ progress bar (REVIEW/ITEMS, YOUR RESPONSES, “ครบทุกข้อแล้ว”, “คำตอบครบแล้ว”) และเอาคำเตือนที่ซ้ำกับแถบบนออก; คงหัวข้อหลัก คำแนะนำย้อนแก้ หมวดคำถาม และคำตอบทั้งหมดไว้


## การแก้ไขตัวกรองหลักสูตร
- ช่องมหาวิทยาลัย/คณะ/ประเภทคงเป็นช่องพิมพ์และเลือกคำแนะนำได้ เพิ่มปุ่มล้างเฉพาะช่องเมื่อมีค่า เพื่อช่วยเปลี่ยนคำค้นโดยไม่แตะตัวกรองอื่น; การกรองต้องไม่แทนที่ input element และไม่ทำให้ focus หาย
- เพิ่มปุ่มล้างตัวกรองทั้งหมดสำหรับคืนช่องข้อความและ dropdown ทุกตัวสู่ค่าเริ่มต้นและกลับไปหน้าแรกของรายการ; ตัวกรอง dropdown ยังคงแก้ซ้ำได้ทันทีและค่าที่เลือกต้องคงอยู่เมื่อผลลัพธ์อัปเดต


## เส้นทางหลังทำแบบสอบถาม
เมื่อบันทึกคำตอบข้อสุดท้าย ให้ไปหน้า “สำรวจหลักสูตร” โดยตรงแทนหน้าทบทวน/สรุปผล; แสดงรายการที่มีน้ำหนักหลักสูตรและเรียงตามดัชนีจากคะแนนแบบสอบถามมากไปน้อย พร้อมหัวข้อชัดเจนว่าเป็นคำแนะนำจากแบบสำรวจและไม่ใช่โอกาสสอบติด. การค้นหา/ตัวกรองและลิงก์ MyTCAS ยังใช้ได้; หน้าสรุปผลแบบละเอียดคงไว้เป็นทางเลือก ไม่อยู่ในเส้นทางเริ่มต้น


## คุณสมบัติผู้สมัครและตัวกรองเส้นทางการศึกษา
เพิ่มความสามารถตามคำขอล่าสุดโดยคงเว็บแบบ static ฝั่งไคลเอนต์และสูตรจับคู่เดิมไว้; ไม่สร้าง snapshot หรือ preload ข้อมูลทุกหลักสูตร. `src/mytcas.js` กำหนด mapping จาก `only_formal`, `only_international`, `only_vocational`, `only_non_formal`, `only_ged` เป็นชื่อที่ MyTCAS ใช้ และแปลงค่าที่ชัดเจน `1` เป็นรับ, `2` เป็นไม่รับ, ค่าอื่น/ค่าว่างเป็นไม่มีข้อมูล. ใช้ endpoint JSON เดิมราย `programId` พร้อม cache request ต่อรหัสและจำกัด concurrent fetch.

รายละเอียดแต่ละโครงการใน modal แสดงคุณสมบัติทั้งห้าแยกใต้รอบ/โครงการ ไม่รวมกับเกณฑ์คะแนน; ถ้า field หายหรือไม่รู้ค่าให้แสดงว่าไม่มีข้อมูล ไม่ตีความเป็นไม่รับ. ตัวกรองเส้นทางการศึกษาเพิ่มในหน้า “สำรวจหลักสูตร” และใช้ข้อมูลสดเฉพาะรายการที่ผู้ใช้จำกัดด้วยคำค้น มหาวิทยาลัย คณะ หรือประเภทหลักสูตร; ต้องไม่เกิน 100 `programId` ที่ไม่ซ้ำต่อการค้นหนึ่งครั้งเพื่อหลีกเลี่ยงการร้องขอข้อมูลทั่วประเทศ. หลักสูตรอยู่ในผลที่ผ่านตัวกรองเมื่ออย่างน้อยหนึ่งโครงการระบุรับ (`1`); รหัสที่ข้อมูลว่างหรือดึงไม่สำเร็จแสดงสถานะ/จำนวนที่ยืนยันไม่ได้แยกต่างหาก และไม่ถูกเรียกว่าไม่รับ. การเปลี่ยนและล้างตัวกรองต้องคงตัวกรองเดิมที่ไม่เกี่ยวข้องไว้; ไม่เปลี่ยนคะแนน 55/45 หรือซ่อน/แสดงจำนวนรับเดิม.

หน้าที่เกี่ยวข้อง: `src/mytcas.js` จัดรูปข้อมูลโครงการและจัดการ request/cache; `src/app.js` ใช้ผลค้นหาและควบคุมสถานะตัวกรอง/การโหลด; `styles.css` จัดรูปแบบรายการคุณสมบัติและกล่องสถานะ; `data/SOURCES.md` บันทึก endpoint และความหมายฟิลด์.
