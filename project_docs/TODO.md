## คุณสมบัติผู้สมัครและตัวกรองเส้นทางการศึกษา MyTCAS
- [x] ในรายละเอียดหลักสูตร ให้แสดงคุณสมบัติการศึกษาของแต่ละโครงการแยกตามรอบ/โครงการ ได้แก่ หลักสูตรแกนกลาง (Formal), หลักสูตรนานาชาติ (International), หลักสูตรอาชีวะ (Vocational), หลักสูตรตามอัธยาศัย/กศน. (Non-formal) และ GED; แสดงสถานะ “รับ”, “ไม่รับ” หรือ “ไม่มีข้อมูลใน MyTCAS” ตามฟิลด์ `only_formal`, `only_international`, `only_vocational`, `only_non_formal`, `only_ged`; ค่าไม่อยู่/ไม่รู้จักต้องไม่ถูกแสดงว่า “ไม่รับ” และต้องไม่เปลี่ยนการแสดงคะแนน/จำนวนรับเดิม
- [x] เพิ่มตัวกรองวุฒิ/เส้นทางการศึกษาในหน้า “สำรวจหลักสูตร” เพื่อให้ค้นหารายการที่ MyTCAS ระบุว่ามีสิทธิ์สมัคร โดยดึงข้อมูลสดจาก endpoint ราย `programId` เฉพาะเมื่อผู้ใช้จำกัดผลด้วยคำค้น มหาวิทยาลัย คณะ หรือประเภทหลักสูตร และไม่เกิน 100 `programId` ไม่ซ้ำต่อการค้นหนึ่งครั้ง; ให้แสดงรายการเมื่อมีอย่างน้อยหนึ่งโครงการระบุรับ (`1`), แยกจำนวนรหัสที่ไม่มีข้อมูลหรือดึงไม่สำเร็จออกจากจำนวนที่ไม่รับ, แจ้งให้จำกัดผลเพิ่มเมื่อเกินขอบเขต, คงตัวกรองอื่น/ตัวเรียง/คะแนนจับคู่เดิม และไม่ preload ข้อมูลทุกหลักสูตร
